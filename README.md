# OrarContigo

Rosario y Coronilla en español latinoamericano. Sin cuenta, sin servidor: preferencias solo en `localStorage`.

## Live

https://tzukasa.github.io/OrarContigo/

## Dev

```bash
npm install
npm run dev
npm run build
npm run test:e2e
```

## Deploy (GitHub Pages)

Push to `main` runs `.github/workflows/pages.yml` (`GITHUB_PAGES=1` → Vite `base: /OrarContigo/`).

Manual: `npm run deploy:pages`
